# ТЗ — ЗАПИСЬ.БОТ v1.0

Telegram-бот онлайн-записи клиентов для самозанятых и малого бизнеса в РФ

## КОНТЕКСТ И ЦЕЛЬ

Создать Telegram-бот, который позволяет мастеру (парикмахер, маникюр, репетитор, психолог, тренер и т.д.)
принимать онлайн-запись от клиентов без звонков и переписок.

Клиент открывает ссылку → видит профиль мастера → выбирает услугу и время → записывается.
Мастер получает уведомление и подтверждает.

**Монетизация:** 199 ₽/месяц через Tribute (tribute.tg). Первые 14 дней бесплатно.
+7 дней за каждого приглашённого предпринимателя, который прошёл онбординг.

## КОМПОНЕНТЫ

| Компонент | Что делает |
|-----------|-----------|
| Main Bot (@ZapisBOT) | Онбординг мастера, управление профилем/расписанием/записями |
| Mini App | Страница мастера для клиента — выбор услуги, слота, форма |
| Analytics Bot (@ZapisAnalyticsBot) | Статистика для владельца продукта |
| Tribute Integration | Приём платежей 199 ₽/мес |

## СТЕК

- Python + aiogram 3.x — боты
